05 — Patterns

Structural Block

Blood Red's third job, on top of accent, destructive and ring: a solid-color layout element. It is not a second color. It is a new layout job for the one accent this system already has. Outside the one block, ink and cream dominate every other surface exactly as before.

Three forms, pick one block per layout

Sidebar / nav rail

Full-height solid primary panel, 22% of the viewport wide (min 220px, max 280px), sticky. Holds the wordmark, in-page anchor nav, theme and flavor toggles, an external link and the copyright. Nav links are primary-foreground at 0.75 opacity, 1 on hover. This site's sidebar is the live instance.

Hero band

Solid primary horizontal block, padding 64px by 48px, used once as an alternative to the sidebar. Never combined with it.

Bold word

One word inside a heading or paragraph in primary, at normal weight and size. Independent of the two block forms and may combine with either.

The segment stripe

Two equal solid segments, foreground then primary, 3px tall, used as a static decorative divider or spacer at any length: a 36px marker before a heading (gap 3px), a 64px rule under the hero wordmark (gap 4px), a 140px closing flourish (gap 6px). Always two equal segments in this exact order. Static and decorative only, never interactive or meaningful. Used a handful of times per page, not as a replacement for the default 1px border divider.

The brand-moment device

Exactly one element per page, the hero wordmark, at weight 700 (the heaviest real weight in either sans) combined with a deliberate size jump to 4.5rem, well beyond the heading scale. Zero new color. Every other heading keeps the normal scale. Lux Swiss needs this typographic device because it has no second color to spend on a brand moment the way Tri-Swiss spends its turquoise.

Hover hierarchy

Red is the only accent, so it carries any real hover signal wherever it participates. The Destructive and Accent buttons fill with primary on hover and their text turns primary-foreground; the Interactive card's border moves from border to primary; the sidebar nav link lifts from 0.75 to 1 opacity. Showcase pages demonstrate each as a static Default / Hover pair so the state is visible without a pointer.
