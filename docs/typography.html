02 — Foundations

Typography

Three roles, strictly separated by function, in two font flavors that share the serif and swap only the mono/sans pair. Range comes from weight, not more typefaces. Toggle Space · Geist and Mono · Jost in the sidebar to reskin this page.

Three roles, two flavors

Space Grotesk was drawn from Space Mono: a duotone of one skeleton, mirroring the two-color rule. Zilla Slab is a slab derived from a monospace (Fira Mono), which is why it stays identical in both flavors.

02 — Chapter Title

The brand-moment device. Lux Swiss has no second color, so its one governed brand moment is typographic: exactly one element per page, the hero wordmark, at 4.5rem and weight 700, dramatically larger than the scale allows anywhere else. Every other heading keeps the scale.

Body — the weight axis 300–700

Light 300 — display sub-decks and leads.

Regular 400 — the body voice. Every element earns its place or is removed; difference is expressed through weight, space, and contrast — never by adding a color.

Medium 500 — UI emphasis and active labels. Prefer this over 700.

Bold 700 — strong emphasis, used sparingly.

Long-form serif

Zilla Slab carries long-form editorial body at 1.15rem and 1.5 line-height. It is shared by both flavors and never used for UI: a settings page, a dashboard and a form never see it.

“Difference is expressed through weight, space, and contrast — never by adding a color.”

Heading accent — Jost, governed and optional

A fourth typeface driven through a single dependent role variable, --font-display, not a third flavor. It defaults to var(--font-mono) until the .jost class is applied to <html>, at which point every heading, the hero wordmark and long-form chapter dividers move to Jost 700. Labels, nav, tags, table headers and data values stay on --font-mono directly. Unlike .geist, .jost composes independently with either flavor and with .dark. Load Jost at a single weight, 700.

:root  { --font-display: var(--font-mono); }
.jost  { --font-display: "Jost", ui-sans-serif, system-ui, sans-serif; }

Loading the fonts

Load only the chosen flavor's two families plus Zilla Slab — three families, not five, unless the project needs a live toggle. Both sans faces are variable fonts requested at the four weights used (300/400/500/700); both monos load regular and bold, roman and italic.

<!-- Space flavor (default) -->
<link href="https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@300;400;500;700&family=Space+Mono:ital,wght@0,400;0,700;1,400;1,700&family=Zilla+Slab:ital,wght@0,400;0,500;0,700;1,400&display=swap" rel="stylesheet" />
<!-- Geist flavor -->
<link href="https://fonts.googleapis.com/css2?family=Geist:wght@300;400;500;700&family=Geist+Mono:ital,wght@0,400;0,700;1,400;1,700&family=Zilla+Slab:ital,wght@0,400;0,500;0,700;1,400&display=swap" rel="stylesheet" />
<!-- Heading accent, opt-in -->
<link href="https://fonts.googleapis.com/css2?family=Jost:wght@700&display=swap" rel="stylesheet" />

Content at any length

Same body voice, same measure — spacing holds regardless of length

Short

Updated 3 hours ago.

Medium

A single paragraph reads the same whether it's a card's supporting copy or a page's lead — same measure, same line-height, no separate rule for "short body text."

Long-form

Restraint scales. A single line of UI copy and a full article both draw from the same weight axis and the same measure — nothing about going longer asks for a new typographic idea.

What changes is paragraph spacing, not the voice: each paragraph gets the same top margin as the body rhythm established elsewhere, so a long-form block reads as more of the same system, not a different one.
