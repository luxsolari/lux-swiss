07 — Governance

House Mark

Tri-Swiss and Lux Swiss are Lux Solari's two house-mark design systems: not two variations of one system, but two related, independently governed languages that carry the same personal brand identity into whatever they are applied to. A house mark is the imprint a maker stamps across everything they produce so it reads as theirs regardless of the title.

What they share

  • The same two structural pillars: visible 1px borders, no shadows (elevation is a background step), generous whitespace, uppercase monospace labels, square corners.
  • The same governance discipline: every color, every optional type register, every icon set is explicitly sanctioned and scoped. Nothing ad hoc.
  • The same warm cream base, #f5efe0 in light and near-black ink in dark.
  • The same three-role typography core and the same Space/Geist flavor: Space Mono, Space Grotesk and Zilla Slab by default, or Geist Mono and Geist Sans with the same Zilla Slab via .geist. Typography is not a differentiator between the two; palette, icon set and Structural Block details are.

What is different

Tri-SwissLux Swiss
PaletteTri-tone: ink and cream plus Swiss Red plus a governed Pastel Turquoise highlightStrict duotone: ink and cream plus Blood Red, no third color
Iconsgeist-iconsLucide
Structural BlockSidebar, hero band or bold word for Swiss Red, plus a tri-part ink/red/turquoise segment stripeSidebar, hero band or bold word for Blood Red, plus a two-color ink/red segment stripe and a typographic brand-moment device

Picking one

Use Tri-Swiss when a project wants a bit more chromatic range. Use Lux Swiss when a project wants the starkest possible two-color statement. Both apply the same Swiss-minimalist structural rules underneath: picking one is a palette decision, not a governance one.
